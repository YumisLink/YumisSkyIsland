# 后续服务器整合包基线

此目录是待部署的配置模板，没有启动独立服务器或修改现有实例。当前仍按要求交付源码，不导出发布 JAR。

版本基线为 Minecraft 26.2、Fabric Loader 0.19.3、Fabric API 0.156.0+26.2 和 Java 25。未来服务器及客户端都需要本模组与 Fabric API；客户端需要模组以识别自定义出货箱、商店、提示和 HUD。

`server.properties.example` 设置新的 Yumi 空岛世界类型、50 人上限、视距 6、模拟距离 5，作为测试起点。原版出生保护设为 0，由模组的大厅和领地权限接管。没人在线时按原版默认 60 秒后暂停；市场使用有效游戏 tick，暂停期间不会消耗一天或重抽商店。

这不是已证明能承载 50 人的性能配置。服务器硬件、玩家农场数量和加载范围确定后，需要按[实现记录](../docs/IMPLEMENTATION_STATUS.md)完成多人压测。

部署时只为新世界使用此模板：已有存档修改 `level-type` 不会自动把原地形变成空岛。默认经济配置源为项目的 `config/yumis_sky_island`；实际运行配置路径和保存方法见[开发说明](../docs/DEV_GUIDE.md)。

项目未代替服务器拥有者接受 EULA，也没有开启外网监听或购买/安装额外插件。

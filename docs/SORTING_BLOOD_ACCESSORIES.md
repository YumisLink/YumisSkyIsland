# 分类器与血月饰品

2026-10-18确认并实现；本轮使用新测试存档，不增加旧档迁移。已有I／O／P页面布局保留。

## 分类器操作与规则

右键物品分类器，在独立界面点击“选择来源”，走到箱A右键；再回到设备点击“选择目标”，走到箱B右键。潜行右键、重新打开设备、120秒超时、断线、换队或跨维度会取消临时选择。两箱选择完整后自动运行，可在设备界面暂停、继续或清空绑定。

每台只有一组持续A→B，没有等级。普通单箱／完整大箱属于同队、同维度，来源与目标逻辑中心的三维直线距离最多100格；三个空岛维度各自支持。本队正式成员可管理设备，信任访客不算正式成员。

分类依据是B箱此刻已有的物品注册ID。例如B里有任意一种钻石剑，就接收A里的钻石剑；名称、品质、附魔、耐久和其它组件原样保留，只有完整组件相同才合并堆叠。B里的样本不额外扣除或预留；B清空后暂停匹配。不递归读取箱内潜影盒。

默认每5tick最多搬A箱一个槽位、合计最多64件；空位不足只搬实际能放下的部分。设备、两箱及大箱两半都已加载时才能开始，不强加载、不补离线时间。允许串联、双向和循环，动态样本规则仍生效；多台共同操作同一箱由事务锁串行处理。

单箱扩为大箱保留绑定并重新检查距离、归属和是否变成同箱。拆掉任意已绑定半箱清空整组连接；原坐标重放不能继承。任意镐正常挖回1台、清空绑定；徒手不返还。

工作台合成1台，无额外岛等级锁：

```text
金块  钻石    金块
红石  箱子    红石
漏斗  比较器  漏斗
```

界面为280×222逻辑尺寸。上方A／B卡片、状态、可翻页的只读样本，下方为玩家36格物品栏；设备没有内部储物槽。槽位边框直接从菜单Slot坐标绘制，Shift只在玩家背包与快捷栏之间移动。

## 实现与恢复

`sorting`模块保存设备UUID、队伍／维度／主世界世代、修订、暂停状态及箱体身份。普通箱的持久附件UUID用于区分替换；大箱保存两半身份。网络操作只传设备UUID、预期修订和意图，选箱依据服务端实际右键交互。

`SortingTransactions`在`世界/yumis_sky_island/sorting_operations`追加强制日志后才修改原生槽位，并把应用序号和槽位变化一同保存到原生区块。恢复逐区块检查前／后快照及身份，已应用的目标不会再次加物。首次附加的箱体UUID尚未原生落盘时，只允许依据强制日志及区块回执恢复身份。冲突保持容器锁定并记录错误，不能删除操作日志来“解锁”。

容器锁覆盖玩家、漏斗、方块变化及已有居民／大炮供料入口；重开检查保存与恢复屏障。主世界重开删除本队主世界分类器记录，保留地狱／末地设备。箱体变化监听位于主世界计分早退之前。

`gameplay/sorting.toml`配置间隔、单次上限、全服每tick轮询设备预算及选箱超时，中文注释；本轮不开放实时编辑。

## 血月饰品

| 饰品 | 稀有度 | 启用效果 |
|---|---|---|
| 脚链 | 稀有 | 增加2护甲点，即一个完整护甲图标 |
| 鲨鱼项链 | 稀有 | 当次近战、箭矢、三叉戟攻击按目标护甲减5计算，最低0 |

项链包含PvP和杀戮光环的正常攻击；药水、溅射和俯冲额外伤害排除。实现只改变护甲公式的当次输入，保留韧性、附魔、抗性与原版破甲，不改变目标实际属性。

两件均为血月专属，排除普通饰品随机领取、商店和合成。实物右键永久解锁、空槽尽量启用；占用现有启用槽，重复不消耗。

空岛主世界血月生效时，玩家或其投射物击杀敌人，每件分别独立0.1%，可能同时掉两件；环境死亡不触发，不要求血月出生，遵守原版生物掉落开关，不受抢夺、猎人倍数或品质影响。

血月标记匣为脚链10%、项链10%、原奖池80%，每匣一种奖励，开匣时不要求仍为血月。原奖池25%的地区蛋最终占每匣20%；没有地区蛋的群系仍由原池自身规则处理。饰品不进入渔夫品质流程。普通匣不变。

`gameplay/blood_moon.toml`新增`accessoryMobDropBps=10`（每件）和`accessoryBoxBps=2000`（两件合计），不扩展实时编辑白名单。实际开匣与JEI共用完整概率表，固定饰品概率不受渔力影响。

# NPC入驻与居民经营

规则确认于2026-10-16；2026-10-18起探矿师改为增加矿工行动经验20%，不再增加铁匠。矿物产出保持不变。

## 玩家操作

1. I控制面板切换到同级“居民”Tab，领取本队一次性的免费许可证；后续许可证在普通商店购买，基价1000，沿用行情和常驻倍率，只买不卖。
2. 在本队空岛主世界建造密闭住宅，室内连通空气30～200格；使用完整建材、玻璃、楼梯或台阶围合。栅栏、草花、火把、地毯、水不算墙。
3. 手持许可证依次右键所有门、认可工作站、光源，另绑定完整床、消耗箱、产出箱。首次选择的箱子为消耗箱，第二只为产出箱；面板可指定下一箱的角色。普通单箱和完整大箱均可，两箱独占，不读潜影盒内部。
4. 在屋内Shift＋右键空气提交；服务端重新扫描成功才扣许可证。房屋不能重叠或共享关键设施，可以共墙。初始10栋；声望100／300增加到15／20栋。
5. 消耗箱放食物和用品，产出箱留空位。每个游戏日04:00，每间有效空房独立5%抽取；命中后目标职业25%、普通居民75%，目标职业须解锁且有对应工作站。新登记房屋等待下一次刷新。

I页直接显示居民、供给状态、累计产出批次、房屋和委托。点击“管理”显示用品和产出、输入正版账号、刷新皮肤、驱逐；选中居民后可在空房卡片迁居。右键本队NPC直接打开并选中居民Tab；所有正式队员可操作，信任访客没有管理权。

新增门、认可光源或工作站会暂停房屋，在房屋卡片“补登记”进入免费模式，主手右键新增设施，回屋内在面板提交。正常开门、开箱、睡床保持登记；红石灯熄灭暂停，复明后恢复房屋有效。已登记关键设施拆除、床不完整、箱子合拆或围护漏口取消房屋。

免费补登记可保留房屋原招募目标，岛等级下降也能修复既有住宅；改选新目标和新建住宅仍检查解锁条件。原目标暂未解锁时，新入住抽取按普通居民处理。所有认可光源均须登记并处于点亮状态，另一只火把仍亮着也不能免除登记红石灯的熄灯暂停。

每日先尝试整套供养，缺任一物品则整套不扣、立即停增益；连续3个有效经营日缺供迁出，成功供养清零。满产出箱仍支付生活物资并保留增益，整批不放入、不积欠；大师生产批次只在整批成功放入时增加。所有厨师正常吃饭；多个厨师不叠加免餐周期。

全队离线不招募、不消耗、不生产、不推进迁出期限；恢复后等下一次04:00。房屋或双箱区块未加载时整体暂停，包括增益，不强加载、不追赶。睡眠和管理员下一天共用市场04:00轮次；时间跳过多天结算一轮，回拨、同日重启不重抽。

每位在住居民每天最多一份交付委托，全队最多三份。等概率选面包4／煤炭2／橡木原木8／小麦8／皮革2／纸8；提交扣物并立即加10声望，不发金币或经验。次日过期，居民死亡或迁出取消未完成委托。不设个人好感。

## 经济、生存与外观

专家同类唯一，普通居民逐人累加，售价加法叠加，例如铁匠和3名普通居民对应铁制品＋53%。售价专家清单共36种：木／铁／金／钻石的斧、锄、镐、锹、矛、剑，以及铁／金／钻石四件盔甲；按类型识别所有来源和品质，仍遵守原有禁售条件。树苗、弓弩、附魔书、下界合金等不扩大专家清单。

木料折扣共24种：9种原木、绯红／诡异菌柄、对应11种木板、竹子及竹板。另覆盖铁金锭、钻石、绿宝石，对常驻／每日／隐藏的实际购价生效；不改等级、库存、行情或交易资格。图书管理员与园丁／探矿师经验加法叠加，同类唯一；小额行动经验保留万分位余数。入住、死亡、停工或卸载导致效果变化时，旧购买／出售报价失效，已持久化的成交不重定价。

NPC使用玩家身体、玩家皮肤缓存和宽／纤细模型，属于真实可寻路Mob，不创建玩家身份或TAB条目。白天活动，夜间寻路回床，范围限制为住宅水平32格和本队领地；不跨维度、不强加载、不允许拴走或乘载。怪物、环境、本队正式成员可杀死NPC；外队与访客受保护。全队离线不免伤。死亡／虚空撤销居民和增益，保留有效空房及箱中物品，不产战利品、经验或击杀任务收益。

房屋取消时优先迁到本队有效空房，保留职业；否则停工并获得3个经营日无房宽限。手动迁居等待下一次04:00供养。重开清住宅、居民、声望与扩容，恢复10栋，保留首次免费领取标记；换队时资产留原队。

皮肤只填写3～16位正版账号名，解析成功后保存账号UUID与资料；显示名固定为解析账号名，不能单独改名。手动刷新按已绑定UUID解析，失败保留旧资料，未绑定使用默认玩家皮肤，始终显示NPC和职业标识。异步回调重新校验当前连接、队伍、居民及岛世代。

## 维护与持久化

执行配置为`gameplay/residents.toml`，中文注释，默认与开发实例同步，手改后重启；不添加实时配置白名单或旧存档迁移。房屋、居民、声望、免费领取标记、每日处理轮次、厨师周期及大师批次属于队伍与岛世代；行动经验余数属于个人。

- `ResidentContent`注册许可证、Mob、网络及`resident_receipts`区块附件；`ResidentEntity`负责身份、生存和移动，`ResidentRenderer`复用玩家模型与皮肤缓存。
- `HousingScanner`用有界六面洪泛完整检查封闭与30～200空气格；设施及围护反向索引在计分早退之前接收方块变化，手动、活塞、爆炸、建造杖和大炮共用原版变化入口。
- `ResidentService`统一权限、每日抽取、经营、声望、效果版本、异步账号及世代校验；`ResidentRules`共享固定经济清单，客户端只展示和发意图。
- 许可证领取／消耗和委托提交复用背包恢复事务。`ResidentSupply`整套快照；`ResidentTransactions`先强制写`world/yumis_sky_island/resident_operations/<队伍UUID>.journal`，再保存队伍经营计数，最后按每个原生区块的回执幂等交付箱内格子。未恢复箱子／区块保持锁定，卸载不强加载，重开以世代和日志基线隔离旧记录。

本地测试集中在被忽略的`local-tests`。单元运行`local-tests/run.ps1 -Task Unit -Offline`；客户端专项运行`local-tests/run.ps1 -Task Client -Offline -ClientTestClass cn.yumis.skyisland.clienttest.ResidentScenario`。

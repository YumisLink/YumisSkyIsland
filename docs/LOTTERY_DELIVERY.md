# 单池抽奖／祈愿

O页同级“饰品／抽奖”Tab保留饰品领取；原神模式下显示“祈愿”。每次消耗1张抽奖券（纠缠之缘），只获得1件当前岛等级已解锁的配置奖品。

## 默认奖池与兑换

独立运行配置为`config/yumis_sky_island/gameplay/lottery.toml`，开发实例为`run/config/yumis_sky_island/gameplay/lottery.toml`。每材质包含斧、铲、剑、锄及四件护甲，共32件：铁普通10级，金稀有30级，钻石史诗35级，下界合金传说75级。开服取全部传说条目的最低等级作为抽奖解锁等级；商店购入资格不限制独立奖池。

30级附魔经验或160个人代币（原石）可兑换1张实物券，低等级也可提前积攒。券从0级开始可随机进入每日／隐藏商店，购入基价10万、沿现有行情，不套常驻倍率。当天上架后不限量购买，也可成为悬赏奖品；券可转交、存箱，不能出售。

普通玩家只看到当日UP、最低解锁等级、两个保底剩余次数、兑换资源和已结算结果。配置中的基础概率与完整奖池不通过普通快照发送。

## 保底与UP

基础概率普通62.4%、稀有35%、史诗2%、传说0.6%。连续40抽无传说，第41抽10.54%，此后每抽增加9.94个百分点，第50抽100%；其它三档按原比例缩小。出传说后重计。

出史诗后重计10抽；保底位先判传说，若命中传说，下次成功抽取固定给史诗，仍须付1张券。传说不重置史诗计数。失败操作不推进计数。

每队独立UP，沿游戏04:00市场轮次刷新，有其它合格候选时避开昨日UP；当天候选顺序固定，按当前岛等级选择首个合格项。传说内UP占50%，其它传说等分剩余部分；歪后下一件传说必为抽取当时UP。唯一合格传说必为UP。个人保底、顺延史诗、必UP标记跨日、换队、重开与重连保留。

## 个人代币

主线每次成功领取给当时全队各20，含离线；支线、职业任务及每次悬赏只给本人20。合法重开、重置任务后的新完成可以再次奖励，重复领取请求不能重复入账。

岛屿每升一级给当时全队各20，含离线；同一玩家同一等级永久仅奖励一次，不补入队前等级。初始岛默认跨过1～3级给60。钱包与等级收据存个人资料，奖励与完成／等级收据同笔日志落盘。

## 配置与维护

后续添加奖品时，在奖池文件末尾追加独立条目，例如：

```toml
[[prizes]]
id = "nether_star"
itemId = "minecraft:nether_star"
rarity = "legendary"
islandLevel = 80
```

`id`必须唯一，同档实际奖品模板也不能重复。四档为`common`、`rare`、`epic`、`legendary`；`components`可按26.2物品组件格式配置，未提供时为空。每项固定发1件。最低传说等级下须能兑现各概率档与史诗／传说保底；无效物品、空池或缺档会停用抽奖并记录中文错误，不回退为全商品池。该文件采用严格读取：错误时保留管理员原文件，不由通用配置修复器补回奖品、等级或稀有度，修改正确后重启。

管理员开启`/is admin edit on`后，Ctrl＋】中的抽奖分组可实时改开关、两种兑换成本和基础概率；奖品目录、门槛和保底参数手改重启。人工注释、权限、配置修订及磁盘摘要检查沿现有配置服务保留。

奖励栈专用`yumis_lottery_rarity`标记只决定稀有度显示。修理、铁砧、砂轮与同ID锻造继承主输入；钻石升级下界合金等ID变化时清除该标记。制造品质、附魔、耐久和收购估值沿原规则。

`dailyStock = -1`代表无限库存，但只有当天实际上架才能购买；其它正数库存仍逐张扣减。券图标通过Aseprite MCP制作，源文件为`art/lottery/lottery_ticket.aseprite`，绘制脚本为`tools/draw_lottery_ticket.lua`。

抽奖／兑换共用操作序号，抽奖随机序号仅在成功抽取推进；背包、经验基准、结果、代币和保底同笔持久化，恢复时不重抽、不重新定价。测试期直接同步默认与开发TOML，不新增旧抽奖存档迁移。

# 2026-10-16 玩法修订交付

目标 Minecraft 26.2／Fabric，Java25，模组版本0.1.0-dev。按最终确认方案实现，默认配置与项目开发实例已同步。

| 功能 | 当前行为 |
|---|---|
| O／P | O页同级“饰品／经验抽奖”Tab；P打开职业。原版朋友O、社交P默认解除，已有O/P冲突在读取选项后解除，手动改到其它键的绑定保留 |
| 经验抽奖 | 每次消耗附魔等级并给1件商品；按当前岛等级筛选全部可购商品，忽略当天上架及库存，保留物品组件；获取开关及建筑模板验收仍生效 |
| 缺档与公告 | 无候选稀有度剔除后重新归一；整池为空、等级不足或背包不足不扣费。本人每次得到结果，史诗／传说全服公告 |
| 抽奖恢复 | 个人序号阻止重复请求，奖品及扣级前经验基准与背包一起记入持久凭据；按原版扣等级，保留经验条进度。保存期间锁定背包和经验变更，断线后按当前连接恢复 |
| 饰品实物 | 主手／副手右键消耗1件永久解锁；有空槽自动启用，满槽保留解锁，重复不扣物，鱼饵被动生效 |
| 生电与大炮 | 32份生电候选的图纸售价、成品费均降为原来的25%；房屋／基地／奇观价格保留。大炮基价10万、岛1级常驻，实际购价仍受常驻倍率与行情影响；特殊弹药仍1000货币／1000额度 |
| 农夫经验 | 依据实际来源方块、成熟度和掉落判定。未成熟不计，南瓜／甘蔗／西瓜不计收获经验，品质和职业任务统计保留；职业面板同步说明 |
| 右键收获 | 小麦、胡萝卜、马铃薯、甜菜、下界疣、可可普通右键只收一株并补种，先保留种植材料。连锁键仍收8株，激活连锁锤时16株。甜浆果沿原版age2／3采摘并回到age1 |
| 梯云纵 | 普通水平初速1.08、向上初速0.49；空格强力上跳保持1.1，冷却与踏云保护保持原规则 |
| 飞行时长 | 同步非负剩余毫秒，以客户端单调时间递减；到期归零并撤销飞行，不再混用两端时间戳 |
| 地狱门 | 首次进入生成完整固定返程门；按玩家保存进入时的主世界门。返程回该门旁的安全位置，原门失效回当前家点；生成冲突拒绝覆盖建筑；换队清入口记录 |
| 虚空救援 | 下界／末地低于Y-100回主世界当前homeXZ、Y325，清动量与摔落距离并给300tick踏云保护；主世界原有救援规则保留 |
| 建造杖 | 冷却使用独立客户端计时，维度／玩家实例／持杖上下文变化清理旧预览并重新同步；服务端拒绝旧维度与旧世代请求，跨维度保留按原维度验证的撤销记录 |
| 特殊钓鱼 | 熔岩复用原版浮力，虚空资格成立立即无重力并固定虚拟表面；两者使用原版等待、咬钩、声音与收杆流程，退出恢复介质与重力状态 |
| XPlus | 可选兼容本机已核验的AutoFish 1.5.1-fabric-mc26.2；使用其正常收杆与再抛调度，未安装时不加载兼容Mixin，不修改第三方JAR或个人实例配置 |
| GUI | 所有自定义面板统一半透明黑灰底色，保留稀有度、任务类型及状态文字颜色；小窗口抽奖列表可滚动到底 |
| 配置 | 同类自动注释仅解释一次，保留手写注释；删除automation/production.toml、unlocks.toml、shipping_chest.toml三份纯资料配置，保留实际recipe_values估值；生成工具不再重建删除文件 |
| 悬赏 | tasks/bounties.toml的rarityWeights实际控制新悬赏奖励，默认稀有70／史诗25／传说5，可手改重启；下一天命令不快进悬赏期限 |

管理员新增命令支持游戏内和控制台，次数为正整数：

```text
/is admin accessory draws <在线玩家> <次数>
/is admin nextday
/is admin bloodmoon tonight
```

第一条在原有次数上增加；下一天到下一次04:00，正常推进商店、行情、共享库存和售出额度；悬赏仅随实际服务器tick计时。血月命令白天快进今日13000tick入夜，已在夜晚直接开启，状态先持久化，重置未命中计数。

导出文件：`build/libs/YumisSkyIsland-0.1.0-dev.jar`、`YumisSkyIsland-0.1.0-dev-config.zip`、`YumisSkyIsland-server-prefabs.zip`。JAR用于服务端和客户端；配置包为23份默认TOML，外置建筑包解压到服务器实例根目录。生电图纸价与成品费保存在外置建筑包的catalog.toml，仅替换JAR不会覆盖已有实例的商品或建筑价格。当前测试期直接同步默认和开发配置，不新增迁移流程；保留手改配置时合并对应条目。

验证已通过：85项JUnit，0失败／错误／跳过；正式编译与导出；配置和JAR内23份默认TOML逐份哈希一致；默认／开发配置的价格、权重、删除文件及重复同步幂等检查；经济文档工具在临时目录完成读入、校验和生成，未重写正式价目文档。

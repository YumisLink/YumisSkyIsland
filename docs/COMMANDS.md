# Yumi’s Sky Island 模组指令表

适用版本：`0.1.0-dev`，Minecraft 26.2 / Fabric。更新日期：2026-10-16，按当前源码核对。

本文收录全部35种模组命令用法，并附管理员渔力命令、默认按键和物品操作。游戏中的 `/is help` 提供常用命令摘要，完整参数以本文为准。

## 输入方式与权限

- 在游戏聊天框中输入命令时保留开头的 `/`；服务器控制台执行时省略 `/`。
- `<玩家>`、`<金额>`、`<次数>`、`<确认码>` 是需要替换的参数，输入时不带尖括号。多词命令之间使用空格。
- “普通玩家”不要求已有队伍；“队员”包括岛主；“岛主”是当前队伍所有者；“管理员”需要服务器授予游戏管理权限。
- 模组聊天命令需要在以 **Yumi 空岛** 世界预设创建的存档中使用。梯云纵也可在安装本模组的普通生存世界使用。
- 管理员的设置余额、增加饰品抽奖次数、下一天、强制血月命令支持控制台；其余模组命令需要由游戏中的玩家执行。
- 默认开启原神模式，货币显示为“摩拉”；关闭后显示为“金币”。下文统一称“货币”或“余额”，金额和交易规则不随称呼变化。

## 建岛与传送

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is` | 普通玩家 | 返回本队主世界空岛；没有队伍时恢复本人休眠的个人岛，或创建新岛。 |
| `/is create` | 普通玩家 | 与 `/is` 相同；已有队伍时返回本队空岛。 |
| `/is home` | 普通玩家 | 与 `/is` 相同；没有队伍时也会恢复或创建个人岛。 |
| `/is sethome` | 队员 | 将当前位置设为全队共用的回家点。必须在本队主世界领地内，脚下有安全地面，脚部与头部空间均为空气。 |
| `/is spawn` | 普通玩家 | 返回公共大厅。 |
| `/is visit <玩家>` | 普通玩家 | 前往指定玩家当前队伍的主世界回家点。目标需有有效空岛；访问本身不授予建造或容器交互权限。 |

回家和访问都会检查落点安全性。目标岛正在重开时不能前往；访客也不能代替成员生成尚未就绪的初始岛。当前初始岛的补给放在箱子内：**3块冰、1桶岩浆**；重开后重新生成同样的初始补给。

## 队伍与访客授权

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is invite <玩家>` | 岛主 | 邀请一名在线玩家加入本队。邀请有效期为6000个游戏刻，正常运行时约5分钟。 |
| `/is accept` | 普通玩家 | 接受当前有效邀请并前往新队伍空岛。若本人是拥有其他队员的岛主，需先移交岛主身份。 |
| `/is reject` | 普通玩家 | 拒绝并清除当前邀请。 |
| `/is leave` | 非岛主队员 | 离开当前队伍，恢复本人的个人岛；没有可恢复个人岛时创建新岛。岛主需先移交；唯一成员的岛主可接受其他队伍邀请或重开本岛。 |
| `/is transfer <玩家>` | 岛主 | 将岛主身份移交给另一名现有队员；目标可以离线。 |
| `/is kick <玩家>` | 岛主 | 移出一名在线队员，使其回到本人的个人岛；不能移出自己。 |
| `/is team` | 队员 | 列出本队岛主与队员。 |
| `/is trust <玩家>` | 岛主 | 授予指定玩家本队领地的建造与容器交互权限，不改变其队伍归属。 |
| `/is untrust <玩家>` | 岛主 | 撤销通过 `/is trust` 授予的访客权限。现有队员仍保有成员权限。 |

`invite`、`kick` 以及管理员设置余额、增加饰品次数的目标必须在线。`transfer`、`trust`、`untrust`、`visit`、`info <玩家>` 按名字查找模组已记录的玩家，目标可以离线。

接受邀请不会把原队伍余额带到新队伍。本人仍拥有的原个人岛及钱包保留休眠；离队或被移出时尝试恢复个人岛。个人职业、支线、职业任务和饰品解锁保留；离队不会重置当日售出额度。

受信任访客可以在授权范围内建造和交互；**蓝图大炮的操作仍只允许正式队员**。

## 查询与计分刷新

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is info` | 队员 | 查看本队名称、岛等级、当前计分、共享余额、领地范围、成员数，以及刷新或重开进度。 |
| `/is info <玩家>` | 普通玩家 | 查看指定玩家当前队伍的上述信息；目标需有有效空岛。 |
| `/is level` | 队员 | 与 `/is info` 相同，也可用于查看刷新进度。 |
| `/is top` | 普通玩家 | 查看空岛前10名。按岛等级降序排列，同级按当前计分降序排列；无成员的休眠队伍不参与。 |
| `/is profession` | 普通玩家 | 在聊天栏查看本人的七种职业等级；职业详情和职业商店按 **P** 打开。 |
| `/refresh` | 队员 | 分批重算本队主世界计分。已暂停的任务继续扫描；正在扫描时提示查看进度。重开期间不可发起。 |
| `/is help` | 普通玩家 | 显示常用模组命令提示。 |

岛等级记录本队历史最高等级；当前计分按主世界现有方块存量计算。拆除方块会降低当前计分，历史最高等级在重开前保留。`/refresh` 读取本岛当前世代的历史放置区块索引；飞行或加载区块本身不会增加计分扫描范围。

## 商店、出售与余额

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/shop` | 普通玩家 | 打开“控制面板”，与默认按键 **I** 相同。商店、收藏、任务和悬赏在面板内切换；购买和出售需要先创建或加入队伍。 |
| `/sell` | 队员 | 与 `/sell hand` 相同，打开主手物品的出售预览。 |
| `/sell hand` | 队员 | 打开出售预览，仅允许选择当前主手所在快捷栏格的可售物品及数量。 |
| `/sell inventory` | 队员 | 打开背包出售预览，可选择快捷栏和主背包共36格中的可售物品及数量；不包含装备栏和副手。 |
| `/balance` | 队员 | 查看本队共享余额。 |

出售需要在控制面板内选择物品、查看报价并确认。**打开预览不扣物，确认后才成交**；服务端会重新检查物品、行情和额度。整笔收益至少为1单位货币才可成交，收入进入当前队伍共享钱包；重开期间暂停交易。

## 空岛重开

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is reset` | 岛主 | 显示重开说明并生成六位确认码，有效期为1200个游戏刻，正常运行时约60秒。 |
| `/is reset confirm <确认码>` | 岛主 | 使用确认码执行本队主世界重开。确认码使用后失效；输入错误或过期后，需重新执行 `/is reset`。 |

| 处理方式 | 范围 |
| --- | --- |
| 清除 | 本队主世界领地内的方块和非玩家实体、共享余额、当前计分、历史最高岛等级、本队岛内死亡计数、队伍主线、悬赏格、售出历史和首获记录。 |
| 保留 | 玩家随身物品、个人职业、个人支线及职业任务的计数和完成状态、个人饰品解锁及待抽次数、本队下界与末地、当日行情、商店库存和售出额度。 |

确认后分批清理，位于本队主世界领地的在线玩家会先移到大厅。完成后可重新生成初始岛，岛主在线时自动回岛。服务器重启后可继续尚未完成的重开任务。清理期间可通过 `/is info` 或 `/is level` 查看进度。

## 管理员命令

以下命令均需游戏管理权限；目标玩家所属队伍与执行管理员所属队伍可以不同。

| 指令 | 执行位置 | 用途与参数 |
| --- | --- | --- |
| `/is admin coins <玩家> <金额>` | 游戏内管理员／控制台 | 将指定在线玩家所属队伍的共享余额**设置为**指定金额。目标需已有队伍；金额为0～9223372036854775807的整数。 |
| `/is admin accessory draws <玩家> <次数>` | 游戏内管理员／控制台 | 为指定在线玩家**增加**个人待领取饰品抽奖次数；在 **O → 饰品 → 随机领取** 使用。次数为1～2147483647的整数，增加后的总次数也不能溢出。 |
| `/is admin nextday` | 游戏内管理员／控制台 | 将主世界时间推进到下一次每日刷新时刻，默认 **04:00**，触发正常每日玩法刷新；悬赏剩余有效时间不快进。 |
| `/is admin bloodmoon tonight` | 游戏内管理员／控制台 | 白天快进到今天夜晚并开启血月；已经入夜时立即开启，不倒退时间。 |
| `/is admin edit on` | 游戏内管理员 | 开启本人统一编辑模式；任务与商店内嵌编辑，Ctrl＋】打开实时配置表单。 |
| `/is admin edit off` | 游戏内管理员 | 关闭本人的所有编辑模式。 |

游戏内示例：

```text
/is admin coins Steve 100000
/is admin accessory draws Steve 5
/is admin nextday
/is admin bloodmoon tonight
/is admin edit on
/is admin edit off
```

第一条将 Steve 所在队伍的余额设置为10万；第二条为 Steve 本人增加5次饰品抽奖。金额、次数填写完整整数，不使用“万”“亿”、千位逗号或小数。控制台例如输入 `is admin coins Steve 100000`。

`nextday` 的刷新时刻读取运行配置 `shop/shops.toml` 中的 `market.refreshAtDayTick`，默认22000，对应04:00；即使当前恰好处于刷新时刻，也推进到下一次。

统一编辑模式只影响执行指令的管理员，退出服务器或失去管理权限后需要重新开启。任务编辑器内保存的定义立即全服生效；单任务进度重置也在编辑器中操作，覆盖相应队伍或个人（含离线玩家），已发放的奖励不回收。每日“查看所有”仅供查看和编辑，不开放未解锁、未上架或仅收购商品的购买。

## 管理员渔力命令

渔力使用原版 `/attribute` 命令，属性ID为 `yumis_sky_island:fishing_power`。以下命令需要原版属性命令权限；`<玩家>` 指一名在线玩家，在游戏内操作自己时可用 `@s`，控制台使用玩家名。

| 指令 | 用途 |
| --- | --- |
| `/attribute <玩家> yumis_sky_island:fishing_power get` | 查询计入职业、饰品等修正后的总渔力。 |
| `/attribute <玩家> yumis_sky_island:fishing_power base get` | 查询渔力基础值。 |
| `/attribute <玩家> yumis_sky_island:fishing_power base set <数值>` | 设置渔力基础值，支持小数；职业和饰品加成继续独立计算。 |

例如 `/attribute Steve yumis_sky_island:fishing_power base set 2.5` 将 Steve 的基础渔力设置为2.5。默认基础值0，最终总渔力范围0～1000；本人可通过 **P → 渔夫** 查看总值及加成来源。

## 默认按键与常用交互

表中均为默认按键；模组按键可在游戏控制设置中重新绑定。`A` 收藏仅在控制面板内悬停商品时生效。

| 默认按键／操作 | 用途与条件 |
| --- | --- |
| **I** | 打开“控制面板”，与 `/shop` 相同。 |
| **O** | 打开个人页面，在同级“饰品／经验抽奖”Tab之间切换。 |
| **P** | 打开职业页面，查看七种职业及个人职业商店；渔夫页展示渔力来源。 |
| **A** | 在控制面板内悬停商品时，加入或移出收藏。 |
| **C** | 施放梯云纵，沿朝向斜上跃起。 |
| **跳跃键 + C** | 施放强力向上梯云纵；默认跳跃键为空格。 |
| **按住反引号键（Esc下方、标有波浪号的键）并破坏方块** | 连锁采集相邻同类方块；基础8块，矿工每5级加1，启用连锁锤再加8，最多128块；实际还受个人设置限制。 |
| **I → 左下角设置** | 设置个人启用的最大连锁数量（1～128，包含起始方块）；实际不超过当前可用上限。默认128跟随上限，原界面大小选项也在此页。 |
| **右键成熟作物** | 单株收获并补种，支持小麦、胡萝卜、马铃薯、甜菜、下界疣、可可；按住连锁键可批量处理。甜浆果普通右键沿用原版采摘。 |
| **右键饰品实物** | 消耗1件永久解锁；有空槽时尽量自动启用，满槽保留解锁。已解锁的重复饰品不消耗，鱼饵解锁后自动生效。 |
| **O → 饰品 → 左键饰品** | 开启或关闭已解锁饰品；普通饰品占启用槽位，鱼饵无需占槽。 |
| **O → 经验抽奖** | 选择消耗10／20／30级附魔经验，获得1件当前岛等级已解锁的可购商品。 |

原版“朋友”O和“社交”P的冲突绑定会解除；已手动改到其他按键的原版绑定保留。

梯云纵地面、空中均可施放，两次成功施放至少间隔5个游戏刻；每次刷新200个游戏刻的“踏云护体”，仅免疫摔落伤害。正常运行时分别约为0.25秒、10秒。

经验抽奖不受当天上架与商店库存限制；商品池全空、该档没有可抽奖品或普通背包空间不足时不扣等级。默认稀有度权重如下，缺少某档奖品时按剩余权重归一；仅史诗、传说奖品全服公告。饰品“随机领取”使用个人待抽次数，与消耗经验的抽奖分别结算。

| 消耗附魔等级 | 普通 | 稀有 | 史诗 | 传说 |
| --- | --- | --- | --- | --- |
| 10级 | 80% | 20% | 0% | 0% |
| 20级 | 60% | 30% | 10% | 0% |
| 30级 | 0% | 70% | 25% | 5% |

## 建造杖操作

需手持建造杖，仅在空岛世界使用；设置界面独立于I控制面板。

| 操作 | 用途 |
| --- | --- |
| **右键方块表面** | 按服务端预览扩建；副手方块可优先指定建材。 |
| **Shift + 滚轮** | 切换建造方向。 |
| **V** 或 **Shift + 右键空气** | 打开建造杖设置。 |
| **Shift + 左Ctrl + 右键** | 撤销最近一次建造中仍有效的方块；需在对应维度瞄准该次建造位置附近3格内的方块。 |

六档单次新增上限为3／9／14／18／64／256，创造模式同样遵守。默认保留最近3次撤销记录，断线清空；已变化或失去权限的位置跳过，只退还实际撤销的耗材，背包满时掉在本人脚边。跨维度会保留服务端记录，返回原维度后按原位置检查。

建材从背包及随身潜影盒／收纳袋的一层内容读取；详细材料限制和升级方式见[建造杖交付说明](CONSTRUCTION_WAND_DELIVERY.md)。

## 预制图纸与蓝图大炮操作

| 操作 | 用途 |
| --- | --- |
| **手持图纸右键** | 打开定位与投影预览；通过界面移动、上下调整、按允许的朝向旋转90°，并切换是否替换。 |
| **定位界面右键** | 切换查看模式；查看模式下可用移动键和跳跃键走动观察，再右键返回操作。 |
| **Esc** | 关闭定位界面，继续走动查看投影。 |
| **G** | 存在当前图纸预览时，重新打开定位界面。 |
| **保存位置到图纸** | 将当前维度、位置、旋转及替换设置写入这张图纸。 |
| **右键本队蓝图大炮** | 装入已定位图纸与特殊弹药，选择自备材料或成品模式，开始、暂停、继续或终止施工。 |

投影最终占地就是施工范围。每次开工消耗1张图纸，成品模式另扣固定成品费；两种模式都逐块施工，默认每5个游戏刻最多1块。特殊弹药默认实际1000货币购买1000次额度，不叠加行情或常驻商店倍率。

大炮只读取炮内及六面直接相邻的本队容器，支持一层潜影盒。缺料、缺弹药或目标区块未加载时自动等待；终止或拆炮保留已建部分，不退已用图纸及成品费，保留未用材料与弹药。**大炮施工没有撤销**。详细流程与外置建筑库要求见[预制建筑交付说明](PREFAB_BUILDING_DELIVERY.md)。

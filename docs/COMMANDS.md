# Yumi’s Sky Island 模组指令表

适用版本：`0.1.0-dev`，Minecraft 26.2 / Fabric。更新日期：2026-10-14。

以下指令用于以 **Yumi 空岛** 世界预设创建的存档。玩家在聊天框输入时保留开头的 `/`；服务器控制台执行时省略 `/`。除设置金币指令外，其余指令均需由游戏中的玩家执行。

`<玩家>`、`<金额>`、`<确认码>` 表示需要替换的参数，输入时不带尖括号。表中的“队员”包括岛主；“岛主”是队伍所有者；“管理员”需要服务器授予的游戏管理权限。

## 建岛与传送

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is` | 普通玩家 | 返回当前队伍的主世界空岛；没有队伍时，恢复自己的休眠个人岛或创建新岛。 |
| `/is create` | 普通玩家 | 与 `/is` 相同；已有队伍时返回当前岛。 |
| `/is home` | 普通玩家 | 与 `/is` 相同，返回空岛。 |
| `/is sethome` | 队员 | 将当前位置设为全队共用的回家点。必须位于本队主世界领地，脚下有安全地面，脚部与头部空间为空气。 |
| `/is spawn` | 普通玩家 | 返回公共大厅。 |
| `/is visit <玩家>` | 普通玩家 | 前往指定玩家当前队伍的主世界空岛。对方需有有效空岛；访问不授予建造或容器交互权限。 |

回家和访问均会检查回家点是否安全；目标岛正在重开时暂时无法前往。首次生成空岛会发放水桶和岩浆桶。

## 队伍与授权

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is invite <玩家>` | 岛主 | 邀请一名在线玩家加入本队。邀请有效期为5分钟游戏运行时间。 |
| `/is accept` | 普通玩家 | 接受有效邀请并前往新队伍空岛。若自己是拥有其他队员的岛主，需先移交岛主身份。 |
| `/is reject` | 普通玩家 | 拒绝并清除当前邀请。 |
| `/is leave` | 非岛主队员 | 离开队伍，恢复自己的个人岛；没有可恢复个人岛时创建新岛。岛主需先移交，唯一成员的岛主不能使用此指令离队。 |
| `/is transfer <玩家>` | 岛主 | 将岛主身份移交给另一名现有队员；该队员可以离线。 |
| `/is kick <玩家>` | 岛主 | 移出一名在线队员，使其回到自己的个人岛；不能移出自己。 |
| `/is team` | 队员 | 列出本队岛主与队员。 |
| `/is trust <玩家>` | 岛主 | 授予指定玩家建造与容器交互权限，不改变其队伍归属。 |
| `/is untrust <玩家>` | 岛主 | 撤销通过 `/is trust` 授予的权限。 |

`invite`、`kick` 和管理员金币指令的目标必须在线。`transfer`、`trust`、`untrust`、`visit`、`info <玩家>` 按名字查找已进入过本空岛存档的玩家，目标可以离线。

加入其他队伍时，原个人岛和原钱包保留休眠。离队和移出队伍不会带走原队伍金币；个人职业、个人支线与职业任务进度保留。对现有队员使用 `untrust` 不会取消其成员权限，需要移出队伍才会失去成员权限。

## 查询与计分刷新

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is info` | 队员 | 查看本队名称、岛等级、当前计分、共享金币、领地范围、成员数及正在进行的刷新或重开进度。 |
| `/is info <玩家>` | 普通玩家 | 查看指定玩家当前队伍的上述信息；对方需有有效空岛。 |
| `/is level` | 队员 | 与 `/is info` 相同，也可用于查看刷新进度。 |
| `/is top` | 普通玩家 | 查看空岛前10名。按岛等级降序排列，同级按当前计分降序排列；休眠的无成员队伍不参与。 |
| `/is profession` | 普通玩家 | 查看本人的渔夫、农夫、铁匠、石匠、工匠、厨师、猎人七种职业等级。 |
| `/refresh` | 队员 | 分批重算本队主世界计分；若任务已暂停则继续扫描，正在扫描时提示查看进度。重开期间不可发起刷新。 |
| `/is help` | 普通玩家 | 显示游戏内的常用指令提示。 |

查询显示的岛等级是本队历史最高岛等级；计分按主世界当前方块存量计算。拆除方块可降低当前计分，历史最高等级在重开前保留。`/refresh` 使用本岛当前世代的历史放置区块索引重算计分。

## 商店与金币

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/shop` | 普通玩家 | 打开控制面板，与默认按键 **I** 相同。面板中可切换商店、收藏、任务与悬赏。购买和出售需要先创建或加入队伍。 |
| `/sell` | 队员 | 与 `/sell hand` 相同，打开主手物品的出售预览。 |
| `/sell hand` | 队员 | 打开出售预览，仅允许选择当前主手所在快捷栏格的可售物品及数量。 |
| `/sell inventory` | 队员 | 打开背包出售预览，从快捷栏和主背包共36格中选择可售物品及数量；不包含装备栏和副手。 |
| `/balance` | 队员 | 查看本队共享金币余额。 |

出售需在控制面板中选择物品、查看报价并确认，打开预览时不扣物。确认时服务器会重新检查物品、行情和额度；整笔收益至少为1金币才可成交，收益进入当前队伍共享钱包。重开期间暂停交易。

## 空岛重开

| 指令 | 权限 | 用途与条件 |
| --- | --- | --- |
| `/is reset` | 岛主 | 查看重开说明并获取六位确认码，有效期为60秒游戏运行时间。 |
| `/is reset confirm <确认码>` | 岛主 | 使用有效确认码执行本队主世界重开。输入错误或过期后，需重新执行 `/is reset` 获取确认码。 |

| 重开处理 | 内容 |
| --- | --- |
| 清除 | 本队主世界领地内的方块和非玩家实体、共享金币、计分与历史最高岛等级、队伍主线、悬赏格、售出历史和首获记录。 |
| 保留 | 个人物品、个人职业、个人支线与职业任务的计数和完成状态、下界与末地、当日行情、商店库存和售出额度。 |

重开会分批处理，位于本队主世界领地的在线玩家会先移到大厅。完成后重新生成初始岛；若岛主在线会自动回岛。服务器重启后可继续未完成的重开任务。

## 管理员指令

| 指令 | 执行位置 | 用途与条件 |
| --- | --- | --- |
| `/is admin coins <玩家> <金额>` | 游戏中的管理员或服务器控制台 | 将指定在线玩家所属队伍的共享金币**直接设置**为该金额。目标需已创建或加入队伍；金额为0～9223372036854775807的整数。 |
| `/is admin tasks edit on` | 游戏中的管理员 | 开启本人的任务编辑模式，并打开控制面板中的任务编辑区域。 |
| `/is admin tasks edit off` | 游戏中的管理员 | 关闭本人的任务编辑模式。 |

例如 `/is admin coins Steve 100000` 会把 Steve 所在队伍的余额设置为10万金币。`<金额>` 填写完整整数，不使用“万”“亿”或小数。控制台对应写法为 `is admin coins Steve 100000`。

任务编辑模式由上述 `on`、`off` 两条指令切换。开启后在控制面板内编辑；保存后的任务定义立即全服生效。编辑模式只作用于执行指令的管理员，退出服务器后需要重新开启。

## 常用按键

| 默认按键 | 用途 |
| --- | --- |
| **I** | 打开控制面板。 |
| **A** | 悬停商品时切换收藏。 |
| **C** | 使用梯云纵，沿朝向斜上跃起。 |
| **跳跃键 + C** | 使用更强的向上梯云纵；默认跳跃键为空格。 |

梯云纵也可用于普通生存世界；两次成功施放间隔至少5个游戏刻，每次获得或刷新200个游戏刻的踏云护体，仅免疫摔落伤害。I、C 可在游戏控制设置中重新绑定。

# Yumi’s Sky Island 第一版开发基线

目标为可长期游玩的10～50人Fabric服务器整合包。玩法、价格及生电计划已先形成 MD/JSON，再据此实现开发源码。现在可直接启动 26.2 开发客户端；当前完成情况见[实现与验证记录](IMPLEMENTATION_STATUS.md)。尚未导出发布 JAR，也未修改现有游戏实例。

## 版本与项目边界

- Minecraft 26.2；Fabric Loader 0.19.3；Fabric API 0.156.0+26.2；Java 25。
- 工程使用 Loom 1.17.21、Gradle 9.5.1；已根据本机 26.2 原版类核对真实 API 签名并完成编译。
- 开发目录：C:\GameApp\YumisSkyIsland。原版核查来源：C:\Users\63569\Desktop\pcl\.minecraft\versions\xplus。实例保持只读。
- 本模组负责领地、经济、商店、职业和空岛生成；不要求Bukkit/Paper插件或Carpet依赖。

## 空岛、队伍与保护

主世界、地狱、末地自然地形与结构为空，保留正常生物群系和刷怪条件。主世界初始岛是6×6×6泥土、一棵橡树、一桶水和一桶岩浆。必需传送门/安全落脚平台可产生少量方块；关闭原末影龙战斗生成流程。

每个party在每个维度各拥有10000×10000水平区域。主世界第一块为X/Z均在[0,10000)，岛靠近区域中心；后续分配不重叠的大区。区域边界统一用包含下界、不包含上界的坐标规则，不能在10000边界被两队同时认领。

新玩家在远离分配区域的大厅出生。大厅只有一层20×20草方块，普通玩家不能改造；管理员可放置/破坏。大厅坐标与正向空岛分配区独立，不挤占岛区。

传送必须绑定目标party，不能直接用原版地狱8:1坐标换算进入另一队区域；跨维度归属验证和安全落脚一起执行。回家点不能设在他人岛、大厅外或无安全落脚处。

成员共享岛等级、金币、研究和市场库存。个人六职业各自成长，原个人岛/钱包休眠保留；加入不自动合并资产，离开不把队伍钱包分走。每人同时只有一个有效party；原版死亡掉落保留。

岛主有其他队员时必须先 `/is transfer <队员>` 手动移交，才能离队或加入另一队，不自动推选新岛主。仅一位成员时没有可移交对象，可接受其他队的邀请使个人岛休眠，或重开本岛。研究/项目任务属于后续计划，当前源码提供保留字段，尚无可玩的研究菜单。

外部授权玩家与party成员分开。授权只给指定岛建造/交互权限，不能自动获得共享钱包和管理命令。访客默认无改造及容器权限；管理员绕过独立处理。

保护覆盖放置、破坏、容器、流体、活塞、爆炸、实体改造和跨界漏斗/矿车转移。权限撤销还需检查已打开的容器及后续取物，不只判断第一次右键。

重开免费、无冷却，由岛主二次确认；只清主世界岛地形/建筑/非玩家实体与共享金币，恢复初始岛并重算等级。背包、装备、末影箱、个人职业、任务/研究、地狱和末地保留。保留背包意味着重复积累开局物资，按已确认规则允许。

清理只针对本队真实生成的区块，不整文件删除可能包含其他岛的共享区域文件。重开保存任务状态与恢复进度，partyId和商店轮次保持，日商品库存与售出额度不重置。

## 等级、商店与职业

岛等级0～100，只按主世界当前方块存量统计；拆除扣分，不能反复放置刷永久等级。初稿每级300点，100级30000点；按同组数量递减：前64块100%、65～320块25%、321～2048块5%、其后1%。原始分数可继续增长。

/refresh入队后立即返回，按区段分批、全服共享预算执行，不扫描整片未生成的10000×10000区域。全空气区段直接跳过，非空区段按预算计数。扫描期间捕获并发增量，完成后发布一致快照。

金币全队共享，64位非负整数保存，右下常驻显示万/亿。日行情相对基准±10%，新基础价值为旧价10倍，正常收购为基础价值的1/100；首种和允许购入的怪物材料购买另乘100倍，不抬高回收价。随后叠加全队原料额度、品质、附魔与耐久折价。

常驻商店只卖普通稀有度；稀有/史诗/传说进入每队限量每日池。每队每自然日5%抽到隐藏池，提高高稀有度物品权重；两类特殊池完全随机无保底，所有购入物品为普通制造品质。

默认I键打开半透明黑色自绘商店，正常字号、名称最多两行，格子默认48且可调40～96。A键收藏置顶，最多30列、按窗口减少实际列数；行情下降绿色、上涨红色。删除的分类隐藏，商品规则以[Q34～Q48确认稿](SHOP_REVISION_REVIEW.md)为准。

常规物品提示有定义才追加实际价值、预计收购、主世界新增放置计分。无价格或无计分的对应行省略。耐久100%→80%时价值100%→50%，80%→50%时价值50%→0%，更低无收购价值；附魔按每个实际等级的配置系数乘算。

个人职业为铁匠、石匠、工匠、厨师、农夫、猎人，均可学习，最高100级。有效手工制作可获取职业经验和一次品质判定；自动化始终普通品质，不给个人制造经验。钻石镐在铁匠65级之后才有高品质资格。

岛存量等级、个人职业、队伍研究、长期生产和终局收藏共同提供目标。稀缺核心物资没有保底，不对主线完成时间作保证。

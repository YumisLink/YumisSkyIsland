## 手动启动

```powershell
.\tools\dev.ps1 -Task Client -Offline
```

使用新存档，选择Yumi空岛并 `/is` 建岛，I打开控制面板；管理员开修改模式。运行配置位于run/config/yumis_sky_island，仓库默认配置修改不会覆盖运行目录已有人工值。任务编辑器逐任务保存立即全服生效；其它运行TOML修改后重启。

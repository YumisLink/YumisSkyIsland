# 李芒果空岛：群系掉落与特殊产出

整理日期：2026-10-18。本文只整理公开资料里能核对到的机制，方便对照，不是本服已实现的规则。

李芒果空岛有群系相关的特殊掉落，数量不多。世界生成时方块被清掉，群系和结构包围盒留着，所以原版“在这个群系刷什么生物”继续生效。真正改战利品表、并且按群系切换物品的，主要是丛林钓鱼。其余特殊物品多数看结构、看生物状态，或看一套独立的可再生规则。

## 群系为什么还能决定掉落

空岛世界按普通世界生成，再把方块去掉。群系、结构位置、结构包围盒都保留。

因此：

- 沙漠仍刷尸壳，下界堡垒仍刷烈焰人，海底神殿包围盒里仍刷守卫者。
- 钓鱼战利品仍读取浮漂所在群系。
- 出生平台、末地传送门框架、带幽匿尖啸体的远古城市传送门框架、蠹虫刷怪笼会留下。堡垒宝藏室的岩浆怪刷怪笼默认不生成，末地随机折跃门也要另开选项。

玩家要先走到对应群系或结构，再在那里钓鱼、刷怪或触发规则。空岛本身没有一张“每个群系一份专属宝箱表”。

## 按群系切换的掉落

### 丛林钓鱼：竹子和可可豆

这是公开资料里最明确的群系掉落。

| 物品 | 出现条件 | 类别 | 来源 |
| --- | --- | --- | --- |
| 竹子 | 浮漂在丛林类群系 | 钓鱼垃圾 | 原版 Java 已有 |
| 可可豆 | 同上 | 钓鱼垃圾 | 数据包补上，对齐基岩版 |

计入的群系包括丛林、竹林和稀疏丛林。1.18.2 曾漏掉稀疏丛林，后续补上了。

机制：

- 无海之眷顾时，鱼、垃圾、宝藏的大类权重仍是 85% / 10% / 5%。群系只改垃圾池里的条目。
- 基岩版丛林垃圾池里，竹子和可可豆各占 10/120。乘上 10% 的垃圾大类，单件大约是全部渔获的 0.83%。1.20.1 实机笔记写的是“两者都在 0.8% 左右”，和这个量级一致。整合包文档没有另给一张精确权重表。
- 两者都算垃圾。垃圾不要求开阔水域，海之眷顾会压低垃圾概率，所以作者用的是简易钓鱼机，而不是开阔水域宝藏机。
- 删掉数据包里的 `data/minecraft/loot_tables/gameplay/fishing/junk.json` 后，可可豆这条消失。竹子仍按原版丛林规则出现。

### 海洋：海豚挖出海洋之心

海豚吃鱼之后，会在海底的沙子或砂砾里挖出海洋之心。必须站在海洋类群系里。文档原话是“海洋之心，不是丛林之心”。海豚需要足够的搜索空间。

关闭指令：`/carpetskyadditions removeDefault renewableHeartsOfTheSea`。

1.18 的旧描述不同：海豚找不到宝藏箱时改为找到海洋之心。当前文档已经改成从沙或砂砾中挖出。

### 下界传送门：群系决定长出的方块

在虚空里生成下界传送门时，门周围会补几格方块。群系决定种类：

- 绯红森林：绯红菌岩
- 诡异森林：诡异菌岩
- 其他下界群系：下界岩

这与基岩版传送门落地的做法对齐。关闭指令：`/carpetskyadditions removeDefault renewableNetherrack`。

1.18 旧包用 9 个腐肉合成下界岩，当前版本改成了这条。

### 沙漠与恶地：游商骑骆驼生成

流浪商人在沙漠或恶地生成时不带商驼，改为骑骆驼。骆驼会随商人消失，骑乘期间不能骑、不能喂、不能拴。这个标签写在 `carpetskyadditions:wandering_trader_spawns_on_camel`。它提供的是骆驼，不是物品掉落。

## 群系决定刷什么，掉落仍是原版

这些内容没有单独做一张群系战利品表。因为群系还在，原版生物和天气规则就还在。1.20.1 实机笔记里实际用过的有这些。

| 地点 | 发生的事 | 拿到的东西 |
| --- | --- | --- |
| 深暗之域 | 敌对生物不刷新 | 刷怪塔放在这里等于空转。作者因此挪了塔 |
| 平原草地 | 刷新猪、牛、羊、马 | 猪用胡萝卜繁殖，再引雷转成僵尸猪灵，打金锭 |
| 河流 | 水中刷新溺尸 | 铜锭。头泡进水转化出的溺尸不掉三叉戟 |
| 海底神殿包围盒 | 守卫者只在结构范围内刷新 | 生鳕鱼、海晶碎片、海晶砂粒 |
| 雪原 | 下雪时炼药锅接细雪 | 细雪，用来冻死岩浆怪 |
| 玄武岩三角洲 | 岩浆怪刷新密度高 | 岩浆膏 |
| 末地高地一带 | 末影人可搬走草方块等可持有方块 | 击杀掉手中的方块 |

引雷的实机写法是“猪被雷劈后，周围 4 格生成僵尸猪灵”。原版规则是被击中的那只猪自己变成僵尸猪灵。笔记和原版措辞不一致，引用时以原版转化为准。

溺尸另有一条当前版本的特殊规则，和铜锭、三叉戟无关：溺尸有 1% 概率副手生成时拿着嗅探兽蛋。这枚蛋死亡不掉。它踩碎海龟蛋时，会用嗅探兽蛋替换被踩掉的那一颗。关闭指令：`/carpetskyadditions removeDefault sniffersFromDrowneds`。

## 按结构或状态判定的特殊掉落

这些经常和群系掉落写在一起。判定读的是结构包围盒，或生物身上的状态。

| 产出 | 触发 | 关闭方式 |
| --- | --- | --- |
| 唱片 Pigstep | 苦力怕在堡垒遗迹里被骷髅杀死 | 删除 `entities/creeper.json` |
| 唱片 otherside | 苦力怕在要塞里被骷髅杀死 | 同上 |
| 唱片残片 5 | 苦力怕在远古城市里被骷髅杀死 | 同上 |
| 远古残骸 | 堡垒中再生的猪灵蛮兵有概率掉落 | 删除 `entities/piglin_brute.json`，或关掉 `piglinsSpawningInBastions` |
| 鞘翅 | 玩家击杀同时带有缓降和漂浮的末影螨，抢夺提高概率 | 删除 `entities/endermite.json` |
| 回响碎片 | 监守者的音爆杀死蝙蝠或海豚 | `removeDefault renewableEchoShards` |
| 迅捷潜行 | 附魔台在监守者 8 格内可以附出 | `removeDefault renewableSwiftSneak` |
| 孢子花 | 盛开的杜鹃花丛被破坏时有概率掉落，时运提高 | 删除 `blocks/flowering_azaliea_leaves.json` |
| 高草丛、大型蕨 | 末影人可以捡起这两种双格植物，击杀后掉出。模组修正了双格方块的放置 | 删除 `tags/blocks/enderman_holdable.json` |
| 蜘蛛网 | 玩家击杀蜘蛛骑士时，先死的那一半掉蜘蛛网 | 删除 `entities/skeleton.json` 和 `spider.json` |
| 猪鼻旗帜图案 | 僵尸疣猪兽被玩家击杀掉落 | 删除 `entities/zoglin.json` |
| 附魔金苹果 | 猫的晨礼里极低概率出现 | 删除 `gameplay/cat_morning_gift.json` |
| 镶金黑石 | 猪灵以物易物时极低概率给出 | 删除 `gameplay/piglin_bartering.json` |
| 熔岩桶 | 村庄英雄礼物，来自盔甲匠、武器匠、工具匠 | 删除 `gameplay/hero_of_the_village` |
| 龙首 | 闪电苦力怕击杀末影龙 | `removeDefault renewableDragonHeads` |
| 潜影贝 | 再次击杀末影龙后，一只潜影贝出现在基岩祭坛顶部 | `removeDefault shulkerSpawning` |

嗅探兽还会把特定结构里的沙子、红沙挖成可疑的沙子，把砂砾挖成可疑的砂砾。沙漠神殿和暖水海底废墟处理沙子，古迹废墟和冷水海底废墟处理砂砾，转化概率 10%。可疑方块使用该结构自己的战利品表。这是结构loot，触发点必须落在结构里。

1.18 还有两条后来换掉的做法：

- 末地钓鱼时，鞘翅可以当宝藏钓出。当前版本改成末影螨的缓降加漂浮。
- 尸壳额外掉沙子。当前版本改成失活珊瑚出水冲成沙，火珊瑚冲成红沙。

## 同包里的其他可再生规则

这些规则补的是空岛拿不到的原版物品。它们不读取群系，列在这里是为了和上面的群系、结构规则分开。

| 产出 | 做法 |
| --- | --- |
| 沙子、红沙 | 失活珊瑚或珊瑚扇有水流出时，每 16–32 秒掉一次沙。火珊瑚掉红沙。每次生成后珊瑚有 3% 概率损坏 |
| 钻石 | 下落的铁砧把一整组煤炭块压成钻石 |
| 地狱疣 | 山羊顶碎地狱疣块 |
| 深板岩 | 浓稠药水把石头变成深板岩。溅射和滞留药水也能转化，概率与药效时长比例有关 |
| 发光地衣 | 闪电打中长在萤石上的藤蔓，或打中萤石上的避雷针 |
| 紫颂果、紫颂花 | 末地折跃门落到虚空上方时，伴生末地石小岛上生成一株紫颂植物 |
| 紫水晶母岩 | 熔岩外包方解石，再外包平滑玄武岩。随机刻约 1/100，平均大约 2 小时变成母岩 |
| 甜浆果 | 狐狸生成时若携带物品，其中 20% 是甜浆果。狐狸很快会吃掉 |
| 菌丝 | 巨型蘑菇长成时向周围扩散菌丝 |
| 枯萎的灌木 | 树苗可以种在沙子和红沙上，之后枯死变成灌木 |
| 悦灵 | 用 5 个正确音符把恼鬼安抚成悦灵。只认音高，不认乐器和八度 |
| 高花 | 流浪商人一级交易出售丁香、玫瑰丛、牡丹、向日葵，各 1 绿宝石、12 次 |
| 方解石、凝灰岩 | 高炉烧制闪长岩得方解石，烧制安山岩得凝灰岩 |
| 发光浆果 | 荧光墨囊加甜浆果合成 |
| 矿石 | 锻造台用基材加矿物块合成。1.18 说明写的是下界岩加金块得到下界金矿石；当前数据包说明改成了基材居中、材料放四边 |
| 马铠 | 对应材料在工作台摆成 H 形 |
| 下界合金升级模板 | 用下界合金锭代替锻造模板，走复制配方 |

珊瑚方块还可以向方解石蔓延。适合度由温度和大陆性计算，理想点大约是温度 0.65、大陆性 -0.3，也就是温暖海岸附近。这用的是气候参数，不是群系 ID。最合适的位置平均约 2 分钟转化一块，最不合适接近 2 小时。

## 版本对照

| 内容 | 1.18 文档 | 1.20.1 实机与当前 1.21 文档 |
| --- | --- | --- |
| 丛林可可豆 | 已有，对齐基岩版 | 仍在。实机同时钓到竹子 |
| 末地鞘翅 | 末地钓鱼宝藏 | 改为击杀带缓降和漂浮的末影螨 |
| 沙子 | 尸壳掉落；红沙用沙子加红色染料 | 珊瑚冲蚀。火珊瑚出红沙 |
| 下界岩 | 9 个腐肉合成 | 虚空下界门按群系生成下界岩或菌岩 |
| 狐狸携带物 | 发光浆果、甜浆果各 15% | 甜浆果 20%。发光浆果改为合成 |
| 苦力怕唱片 | 下界被骷髅杀死可掉全部唱片 | 按堡垒、要塞、远古城市分三种 |
| 海洋之心 | 海豚找不到宝藏箱时获得 | 海洋群系中从沙或砂砾挖出 |

1.20.1 那组发展记录没有把整合包后来新增的每条都玩到。嗅探兽蛋、可疑方块、骆驼游商、珊瑚蔓延，以当前特性文档为准。

# Yumi’s Sky Island 生电、经济与出货箱计划

日期：2026-10-13。目标：Minecraft 26.2，Fabric Loader 0.19.3，Fabric API 0.156.0，Java 25。

这是先于源码制定的规则与配置设计。已读取本机26.2原版资源并核查关键生产机制，现已有对应开发源码和客户端验证；具体范围见[实现与验证记录](IMPLEMENTATION_STATUS.md)。xplus 实例保持只读。价格、等级、库存和性能预算是本项目设计值。

## 用户已确认的边界

| 项目 | 规则 |
|---|---|
| 生电购买门槛 | 只限制商店购买核心物资；自行获得、合成、放置和原版生产不受限 |
| 职业村民 | 禁止交易；保留繁殖、职业工作AI、种田、赠礼和铁傀儡生成 |
| 流浪商人 | 禁止交易 |
| 猪灵 | 保留原版以物易物 |
| 大量生产材料 | 使用低基价，不因没有矿床就把可再生矿物锭设为高价 |
| 每日售出 | 全队共享；前1000原料等份正常收购，之后至10000份半价，再往后十分之一，无数量上限 |
| 相关物品 | 铁粒、铁锭、铁块等按原料单位换算，同组不重复领取满价额度 |
| 出货箱 | 普通箱子外观、特殊合成，红石信号从无到有时出售一次 |
| 出货收益 | 与手动出售同价，进入所在岛队伍的共享钱包 |
| 每日池 | 每队按岛等级独立抽取，限量库存全队共享，完全随机无保底 |
| 隐藏池 | 每队每自然日5%概率替代每日池，提高物品稀有度；不出售高制造品质装备 |

## 生电调查结论与分级

完整链条和逐项门槛见[生电产出表](../config/yumis_sky_island/automation/TECHNICAL_PRODUCTION.md)。判断依据包括26.2本机配方、掉落表、相关实体/方块字节码，以及文末的官方和作者一手资料。

全空世界仍保留正常生物群系与刷怪条件。人工建平台不等于保留自然结构：铁农场、普通刷怪、金塔、猪灵以物易物、人工村庄袭击可以研究；要塞、堡垒、女巫小屋、末地城的专属刷怪范围或初始战利品不能凭平台自动获得。

| 岛等级阶段 | 商店重点 | 建议长期项目 |
|---|---|---|
| 0～4 | 原木、圆石、草方块；高启动价树苗与种子 | 利用开局两个桶稳定刷石，再种植、基础刷怪平台、收集产物 |
| 5～14 | 苔藓／杜鹃5；铁锭／铜锭10；常见作物首种 | 自制堆肥桶，骨粉闭环、泥土再生、作物扩产、多样化建筑计分 |
| 15～24 | 红石粉15；蜜蜂15；村民与硫磺块20 | 用原料自制运输与红石机器，铁农场、出货箱脉冲与溺尸铜 |
| 25～34 | 钟乳石锥25；烈焰棒与金锭30 | 自制炼药锅／酿造台，熔岩补给、泥巴黏土链、酿造、地狱金塔 |
| 35～44 | 钻石与猪灵35；青蛙／紫水晶母块40 | 自制自动合成器，猪灵材料链、紫水晶与蛙明灯条件研究 |
| 45～54 | 五档灾厄瓶、绿宝石／青金石45 | 人工村庄袭击、英雄赠礼，积累特殊商店预算 |
| 55～64 | 末地框架／末地石／首株紫颂花55 | 队伍筹资进入末地，紫颂扩种，建设储存与运输系统 |
| 65～84 | 潜影壳、远古残骸与下界合金升级模板65 | 自制潜影盒，熔炼与锻造终局装备，提高个人制造品质 |
| 85～100 | 等级已解锁的稀缺原料、模板和不能钓出的附魔书 | 稀有物资收集、展示建筑与生产网络维护；研究／任务为后续设计 |

阶段只是建议推进顺序；玩家可以提前完成原版生产设计。机器和装备已经移除商店购买，不再沿用旧稿中的机器等级锁；实际限制只针对保留的原料／首件。铁匠65级的钻石镐品质门槛属于个人职业，不能用岛65级替代。

重要产出区别：

- 铁来自铁傀儡；铜来自满足玩家击杀条件的溺尸；金来自僵尸猪灵等。交易关闭不关闭这些来源。
- 红石可以来自普通女巫；绿宝石、图腾等可来自袭击；青金石可来自村庄英雄牧师赠礼。牧师启动需要酿造台，第一根烈焰棒仍需解决。
- 猪灵产物含石英、砂砾、黑石、灵魂沙等，不能据此推断下界岩、灵魂土也可量产。
- 26.2硫磺尖刺的自然生长需要已有母尖刺与硫磺基底；4尖刺合1硫磺，9硫磺合1浓硫磺。本轮删除了尖刺商品，全空世界没有母尖刺初始来源，不能把当前配置说成可从零启动硫磺农场。硫磺块仍有基础原料供货。朱砂和孢子花没有同样的原版再生链。
- 紫颂花可从特殊店购入，启动后可扩种。潜影贝的弹射繁殖虽是原版机制，但本轮删除了潜影贝蛋，全空末地没有首只来源；当前只允许购买潜影壳材料，不承诺潜影贝农场能够从零启动。
- 紫颂和下界疣种植不限制维度，分别需要末地石与灵魂沙。紫水晶母块需要特殊商店供应，普通紫水晶块不生长；母块精准采集也不能回收。
- 守卫者自然刷怪依赖海底神殿结构范围；纯空无结构不把海晶材料算作无限量产，一枚守卫者蛋也不会建立神殿。
- 没有堡垒刷怪范围时，烈焰棒、凋灵头、煤不能默认按无限农场定价。本轮不售烈焰人／凋灵骷髅蛋；对应保留材料可从每日／隐藏池限量购买。
- 树木、冰、雪、岩浆、农作物有不同采集或玩家参与条件，表中“可再生”不承诺完全挂机。Java甘蔗不接受骨粉，岩浆灌锅不等于原版自动取桶。

不把TNT复制、重力方块复制或Carpet额外规则算进价格基线。这里只规定本方案的经济假设；是否额外阻断具体漏洞应在服务器验收时单独核验。

## 基价与每日售出阶梯

完整价格见[逐项价目](../config/yumis_sky_island/shop/PRICE_GUIDE.md)，原料等份见[售出额度表](../config/yumis_sky_island/shop/SALE_QUOTA_TABLE.md)。本轮按[Q34～Q48](SHOP_REVISION_REVIEW.md)调整交易范围：原木可买可卖，木材方块仅收购；颜色、工具、战斗及多数功能／红石商品禁交易，敌对蛋移除，猪灵蛋保留。禁止购买不会禁止正常原版制作或放置。

| 普通制造品质、无损物品 | 基准全价 | 未超额度收购价/件 |
|---|---:|---:|
| 圆石、竹子、甘蔗、火药 | 100 | 1 |
| 石英、末影珍珠、紫颂果、下界疣 | 200 | 2 |
| 红石粉、骨头 | 300 | 3 |
| 硫磺块 | 400 | 4 |
| 青金石、紫水晶碎片 | 500 | 5 |
| 铁锭、金锭、铜锭、绿宝石 | 900 | 9 |
| 潜影壳 | 20000 | 200 |
| 钻石 | 100000 | 1000 |

每天报价相对基准±10%，基础价值下限100。首种与允许供货的怪物材料购入另乘100倍；这个购买加价不进入收购价。硫磺尖刺、不死图腾等已取消经济定义的产物不再收购。金币以整数保存，估值与阶梯用精确有理数，整笔最终只舍去一次小数。

设正常一件收购价为`V/100`，一件含`u`个原料单位，本次卖`q`件、该组此前已售`c`单位。定义累计权重：

```text
F(x) = min(x,1000)
     + min(max(x-1000,0),9000)/2
     + max(x-10000,0)/10

本行收入 = q × V/100 × [F(c+q×u)-F(c)]/(q×u)
本次金币 = floor(按槽位顺序算出的所有可售行收入之和)
```

`V`包括基础行情、品质、附魔和耐久，额外购买倍率不进入收购。每行推进本次临时计数，成功后才一起保存。

例：此前卖了995铁锭单位，再卖9铁锭，其中5份正常、4份半价，基准正常收购9金币，最终收入63金币。铁块／铁粒当前已禁交易，保留旧单位映射避免更换计数组。

铁锭正常收购9金币时，一自然日售1000、10000、100000锭，累计收入分别为9000、49500、130500金币。以20TPS每小时三轮计，每轮10万锭的公式结果为391500金币/小时；实际产量尚需采样。职业装备现已禁交易，后期财富以仍可收购的原料和制品为主。

超过10000份后的低价不禁止出货。普通1金币材料整批10件还可得到1金币；不足1金币的整次交易不扣物、不计数。出货箱可以保留这些物品，等更多物品加入后再次给脉冲。

计数键固定为`partyId + marketEpoch + quotaGroup`。成员、三个维度、所有出售入口共用；重登、重开、压缩、染色、氧化、品质/附魔变化不能重置。物品今日行情可以不同，换形态选择更高报价是允许的，但额度相同。

历史等份覆盖铁/金/铜、钻石等矿物、金属/钻石工具与玩家盔甲、骨粉/骨块、蜂蜜、羊毛/地毯、冰、硫磺及纯材料加工链、潜影盒等。保留这些稳定映射用于旧世界计数，不重新开放已禁交易的商品。切制铜台阶历史映射按最省切石路径为9/8铜锭；马铠和鹦鹉螺铠没有普通制作配方，未套用玩家盔甲用量。

尚未明确主原料的复杂混合制品暂用原版物品ID独立计数；药水/灾厄瓶/附魔书等标准变体共用其原版ID。这是配置草案当前的覆盖边界，完整加工链逃逸检查列入实现验收，不能把已检查的等份表声称为所有配方都已防绕过。

## 出货箱与禁交易实现要求

出货箱详细行为及合成布局见[出货箱方案](../config/yumis_sky_island/automation/SHIPPING_CHEST.md)。消耗4铁锭、4红石、1箱子，复用原版箱子渲染，27格，不组成大箱子，允许漏斗。合成不设等级锁。

红石邻块通知只比较保存的供电状态；从无到有时入队一次，持续通电不重卖。区块加载读取实际供电建立基线，不把加载当新脉冲；重启恢复已有待处理交易。箱子忙时合并重复请求，不允许无限任务堆积，处理后需要新的上升沿。

绑定来自实际放置所在岛屿的队伍，不根据红石“激活者”猜玩家。每次出货检查该队该维度的领地世代及权限。主世界重开只使旧主世界绑定失效，保留的地狱/末地出货箱仍按原归属工作；当日计数不清空。跨界漏斗、漏斗矿车和其他容器转移同时验证源与目标。

统一`SaleService`完成合法性检查、价格/阶梯计算、钱包溢出检查、交易日志、箱内扣物、金币增加和原料计数增加。未定价、0价值、非法组件、命名贵重物品或非空容器保留。不能先删物再尝试记账。

主线程内事务不能代替磁盘崩溃恢复。为每次出售保存稳定交易ID及提交状态，恢复时锁定受影响钱包/箱子，幂等补齐未完成提交。全服出货计算预算初稿为每tick1毫秒，不强制加载无人区块；实际磁盘日志开销、峰值tick和吞吐要测量。

村民禁交易在服务器阻止`Villager`、`WanderingTrader`打开交易菜单，并在菜单有效性/结果提取路径再次验证。不能仅在交易完成后的通知里取消，因为shift取走结果的路径可能已经移动物品。不拦截猪灵AI的以物易物，也不全局关闭`mobGriefing`影响村民种田与雪傀儡。

## 长期目标与实施顺序

建议保留四条同时推进的目标：岛屿存量等级、个人六职业、队伍研究投入、生产/收藏项目。库存计分拆除会降低等级；职业与已完成研究保留，避免只有无限铺方块这一种长期目标。

任务适合要求完成可核验项目：累计不同产物的真实出货量、完成基础红石运输与手动触发、实际产出某种材料、完成一次袭击、筹集末地预算、制造满足职业门槛的装备、完成终局收藏展示。任务记录生产/交易事件，不要求服务端每tick识别整个农场结构。

自动合成及漏斗提取产物始终普通制造品质，个人制造经验为0；本人消费真实原料并完成有效制作才给职业经验。无损压缩/拆包、复制、预览、维修不刷经验。出货箱只卖物，不把挂机产出变成个人职业经验。

完全随机、无保底的每日池仍是已确认规则。关键初始物资可以提高可编辑抽取权重，但不能承诺80～150小时内必完成；高等级只获得购买资格和候选池，不保证供货。

| 顺序 | 实现内容 | 完成依据 |
|---|---|---|
| 1 | 26.2工程、真实注册表/组件校验、读取配置 | 无静默兜底的错误报告，所有配置引用能解析 |
| 2 | 三维度空生成、起始岛、大厅、队伍领地与权限 | 新存档与多队跨界/门户验证 |
| 3 | 钱包、报价轮次、等份计数、统一买卖事务 | 边界、整数溢出、批量售卖、并发与崩溃恢复验证 |
| 4 | 禁村民/流浪交易；出货箱注册、漏斗与红石 | 两类交易入口关闭，猪灵/铁农场保留；每上升沿一次 |
| 5 | 动态计分、渐进/refresh、快照同步、悬停提示 | 并发放置不漏计，刷新时每tick全服预算实测 |
| 6 | 每队每日/隐藏池及限量库存 | 重启/重登/升降级不重抽，抢购最后库存只成交一次 |
| 7 | 半透明自绘商店、I/A键、格子大小、收藏 | 小窗口自适应，足够宽时30列；展示下一件实际预计收购价 |
| 8 | 职业与品质、研究/项目任务、长线平衡 | 制作只结算一次，自动化不刷个人经验，收益采样校准 |

验收包含：铁粒精确1/9计数；跨1000与10000的单件/整批计算；金币舍去后0不扣物；手动和出货同价；持续供电与重复通知不再卖；掉电再通电可卖；带电区块加载不新卖；扣物/入账各崩溃点不丢物不重复入账；50人、多个出货箱和/refresh同时运行的tick耗时测量。数据、单元测试和客户端场景的验证范围分别记录，尚未完成整套生产服务器验收。

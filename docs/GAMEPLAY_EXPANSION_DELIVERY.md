# 2026-10-15 玩法扩展交付

本轮实现初始补给、飞行券、生态球、地区钓鱼、饰品、职业果实与商店、血月、连锁采集、任务列表过滤和虚空救援。实际交付以源码、可编辑 TOML 和正式构建的 JAR 为准。

## 玩家入口

| 入口 | 行为 |
| --- | --- |
| I 控制面板 | 未解锁和已完成的任务不显示；管理员任务编辑模式仍可查看与编辑全部任务。 |
| O 饰品 | 每达到一个新的岛屿 5 级里程碑，当前每位队员各获得一次随机未解锁饰品领取机会；离线机会保存在个人存档。左键直接开启或关闭，激活格为透明绿色。默认 3 栏，个人栏位数已存档，供后续奖励扩展。 |
| P 职业商店 | 七职业各有一个同级标签页，展示本人的等级、经验和个人职业积分。果实与岩浆／虚空鱼饵在对应页购买。鱼饵拥有后自动生效，不需要渔夫等级或激活栏位。 |
| 按住 `~` | 预览并连锁挖掘相连同种方块，初始上限 8 块；连锁锤饰品激活时上限 16 块。预览以虚线框显示。按住时右键成熟作物可连锁收割并重种，重种需要消耗相应种子。 |
| 背包与 HUD | 岛屿等级常驻右下角；背包上层显示当前等级积分／下一等级门槛。飞行剩余时间显示在快捷栏上方。 |

新岛与重开后的初始箱子放置 3 块冰和 1 桶岩浆；不向玩家背包直接发放水桶或其它初始补给。玩家掉到 Y=-100 以下时回到同一 X/Z 的 Y=325，并获得 15 秒踏云护体。

## 物品与活动

飞行券为 0 级稀有、最大堆叠 4、默认价格 100,000 摩拉／金币的消耗品。每张增加 10 分钟创造飞行时间，可连续叠加；时间按现实时间保存。飞行券不会成为悬赏目标。

65 种生态球覆盖 Minecraft 26.2 原版生态群系，使用后修改玩家当前 16×16 区块的所有高度，并保存在岛屿数据中。稀有 44 种默认 100,000、史诗 17 种默认 250,000、传奇 4 种默认 1,000,000；[完整名称、原版 ID、分档列表](BIOME_BALLS.md)。生态球只购买，不成为悬赏目标。

水域钓鱼保留一半原版产出，另一半使用地区池；沙漠宝藏包括仙人掌，森林和其它有树的群系包括对应树苗，寒冷群系包括蓝冰与浮冰。岩浆和虚空钓鱼需要各自的永久鱼饵饰品。末地鞘翅为**已经抽到宝藏之后**的 0.01% 条件概率。JEI 中分别有“钓鱼”和“血月钓鱼”分类，百分比同样以已出现宝藏为条件，并按无额外钓鱼力和默认配置展示；角色钓鱼力改变时，稀有池权重会变化。

六种职业活动在每次获得正向职业经验时各有 0.1% 概率产出对应果实，每人每种最多食用 100 个。单果增益：铁匠护甲 +0.05、石匠护甲韧性 +0.01、工匠攻击 +0.01、厨师每秒生命回复 +0.01、农夫最大生命 +0.1、猎人掠夺 +0.01。猎人掠夺按整数倍保底与小数概率追加整份掉落计算。

血月每晚判定一次，初始 1%，连续未触发则次夜加 1%，触发后回到 1%。血月主世界所有在场生物的攻击、移动和攻击速度各增加 50%；敌对生物最大生命额外增加 100%，自然生成尝试和数量上限增加至 5 倍，可在亮度小于 12 时生成。血月地区宝藏可抽到当地敌对生物刷怪蛋。

## 配置与边界

新参数在 `config/yumis_sky_island/gameplay/blood_moon.toml` 与 `config/yumis_sky_island/products/profession_shop.toml`，商品价格、等级和稀有度仍由商店 TOML 控制。JEI 是可选的客户端集成，未安装时模组照常运行。连锁挖掘只在空岛世界生效，服务端重新选取方块并检查领地权限。

已运行正式服务端／客户端编译、50 项 JUnit 和带 JEI 的隔离客户端完整场景，均通过。客户端场景覆盖初始箱子、重开后补给与背包保留、既有经济／职业／任务流程及 JEI 分类加载；还直接验证了飞行券、沙漠生态球和铁匠果实的扣物、持久化与实际效果。场景通过后只修正了生态球使用提示文字，并再次通过正式编译与导出。导出的 JAR 逐份校验包含 23 份默认 TOML，测试源码未被打包。血月整夜刷怪强度、长时间多人并发及各群系钓鱼的随机分布还需要实际服务器负载与统计采样。

# 副职业批量出售与物品管理

确认日期：2026-10-19。适用于双端同一版本JAR。

## 玩家操作

I控制面板选择“卖出背包材料”，再点击“副职业产品”。该按钮替换当前勾选，只选本机名单内且服务器允许出售的整堆；随后可以手动改数量，查看服务端报价并确认。范围为36格主背包，包含快捷栏；装备、副手、鼠标持物和容器内部沿现有边界处理。

左下角“设置”内维护出售名单：按中文物品名或ID搜索并添加／移除，也可恢复默认46项。名单为物品ID，普通及全部品质均匹配。修改立即保存到本机 `client.toml` 的 `professionSaleItems` 数组，所有服务器和单机存档共用；显式 `[]` 保持为空，未注册ID保留并在选择时跳过。恢复默认仅替换此名单，保留其它偏好。

默认46项由11种原版作物、4种原版鱼、17种厨师食品、干草块／糖、6种模组鱼及6种突变作物组成。迷之炖菜等当前没有收购定义的食品保留在名单，批量选择时跳过；工具武器盔甲、附魔书、鹦鹉螺壳和四种稀有渔业材料由玩家自行加入。命名、容器内容、未知自定义数据和非法附魔继续使用现有出售保护。

## 管理员操作

先执行 `/is admin edit on`，再从I控制面板原“新增物品”位置进入“物品管理”。商品卡片打开普通详情；Ctrl＋】继续打开原有实时配置表单。

管理列表包含全部非空气注册物品、合法选择器变体和已有配置变体，可搜索名称／ID，按全部、已定价、未定价、已停用筛选。选择物品后在同一滚动区域编辑，底部保存。未定价物品保存时新增定义；将“交易”切为停用后保存会关闭买卖，恢复开启后保留原交易方式与价格。

可编辑购入基价、收购估值基准、买卖方式、启停、稀有度、解锁等级及每日库存；已验收外置建筑图纸另有成品费。金额为正整数，等级0～100，库存为正整数或 `-1`（不限）。购入与收购独立，预览按实际行情、最低估值、作物倍率、居民效果及已用额度计算；没有队伍时显示中性行情。

特殊弹药“购买实际金额”为固定成交价，免行情、常驻倍率和居民折扣，每份额度继续读取 `ammunitionCredits`。开启收购后，仅完整弹药可以出售；拆炮退回的余量弹药显示拒收原因。

药水与附魔书等变体按规范化组件独立定价，服务器生成稳定商品ID，相同实际模板复用既有记录。原有商品ID保留，准确变体优先于通用和局部匹配。

## 配置与生效

`shop/products.toml` 的 `productOverrides` 表以商品ID为键，保存物品管理的最终经济定义。读取顺序为原商品及等级／稀有度配置、外置建筑元数据和旧购价覆盖，最后应用管理记录。手动修改已管理商品时，应编辑该表。

管理记录字段：`baseValueCoins`（收购估值）、`buyBaseValueCoins`（购入基价，特殊弹药为固定金额）、`tradeMode`（`buy_sell`／`buy_only`／`sell_only`）、`tradeEnabled`（缺省true）、`rarity`、`unlockLevel`、`dailyStock`，图纸另有 `buildFee`。新静态商品的源定义与完整管理记录在同文件内保存；其它等级／稀有度文件保留为未管理条目的底值。

保存检查管理员和唯一编辑模式、字段白名单、修订、相关配置磁盘摘要及外置目录；验证后原子保存一个商品文件，再发布内存目录与版本。人工外改会拒绝保存并保留文件；权限撤销或断线清除编辑会话。价格变化使旧购买、出售及大炮开工报价失效。

价格、交易启停、等级及图纸成品费保存后生效。每日库存下次04:00采用，今天供货及剩余库存保留。停用保留内部估值及全商品奖池定义，相关未完成悬赏按现有资格规则刷新。

外置模板仍须满足原有安装、验收状态、SHA256和朝向等要求，经济管理不修改模板资产。商店与大炮开工共用有效等级和成品费。已持久化开工头保留原费用；新工程读取新费用，过期开工报价重新确认。

商品保存按当前奖池模式更新候选，并递增抽奖规则版本。独立奖池仍由 `lottery.toml` 定义；全商品模式保留停用记录。重载保留个人保底、顺延、必UP、操作／随机序号及已落盘奖励，当天仍合格UP与顺序保持。

## 本轮行为

普通常驻购价额外×2.5，通过 `shop/shops.toml` 的 `regularBuyMultiplierBps = 25000` 配置。每日、隐藏及其普通商品回退均按特殊商店上下文核价。可选 `buyBaseValueCoins` 独立控制购入基价；既有基础估值与收购价继续使用 `baseValueCoins`。服务端结算、卡片、详情、数量总价、余额检查和确认文字使用相同上下文。

幽匿尖啸体、感测体和唱片残片5购入基价10万；试炼钥匙5万、不祥试炼钥匙10万，55级稀有。46种供货蛋购入基价为基础估值×10，全部88种蛋的稀有度至少稀有，原42种禁售蛋仍不供货。两个原版空白刷怪笼仅购买，每轮库存1、权重1：试炼笼100万、55级传奇；普通笼1000万、100级传奇。使用原版刷怪蛋设置生物，试炼笼保留原版空白奖池及原版游戏规则。

商品支持 `buy_sell`、`buy_only`、`sell_only`，管理员可直接配置注册物品、组件、价格、等级和稀有度，重启生效。完整例子见 [DEV_GUIDE](DEV_GUIDE.md)。显式默认生成工具以原基础估值计算蛋的购入基价，重复执行不会再乘10；历史生成分类与保留过滤也支持两种仅购买的笼。

任务默认共66项，其中64项为七条个人职业线：渔夫10、农夫4，其余五职业各10。完整目标和奖励见 `config/yumis_sky_island/tasks/quests.toml`。只累计解锁后本人行动，目标达成后手动领取才解锁下一项，不扣目标产物。工作台、切石机、手动领取熔炼、真实渔获、本人破坏产生的掉落及有效本人击杀分别追踪，制造目标独立于经验白名单。树苗限定橡树叶掉落，剪叶限定剪刀；说明和详情均显示这些限制，目标名称采用客户端当前语言的原版译名。

主线全队共享；支线、职业任务及其计数、完成状态和重置版本存于个人记录，换队和重开保留。出货箱支线只给真实成功放置者资格。金币奖励进入领奖时队伍钱包，物品和原版经验发给本人。背包不足保留资格；500点经验写入同一交付凭据，已应用的玩家事务标识阻止重复恢复。

渔夫每次真实成功获钓默认12职业经验，可由 `products/professions.toml` 配置，空收杆与钩实体不计。七职业沿用0～100级曲线。职业任务自身只在“做记号”发500原版经验点。宝藏说明保留原版开放水域条件。

任务按主线、支线、职业排序，标题分别金色、白色、蓝色，选中后保持颜色；职业线默认渔夫、农夫、铁匠、石匠、工匠、厨师、猎人。列表和已打开详情随服务器进度实时同步。任务面板没有编辑模式开关及网络开关操作；管理员仅用 `/is admin tasks edit on|off` 打开同页内嵌编辑器，可编辑职业、前置、追踪条件与原版经验。全服单任务重置覆盖离线个人记录。

持久化成功的队伍金币正增量向本队在线成员发送独立通知，携带队伍和事务序号；客户端200ms窗口合并，显示金色“+金额”，1.8秒上浮24像素并渐隐，不同窗口错位。游戏HUD及控制面板右下角均显示；登录、换队、重连和扣款不由余额差误触发。出货箱物品使用方块描述前缀，复用中英文方块译名。

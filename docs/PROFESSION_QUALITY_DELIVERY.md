# 副职业品质与经济规则交付（2026-10-15）

## 已实现

- 七职业向所有玩家开放。实际本人制作、熔炼领取、切石、收获、钓获和畜养生物击杀，逐件按独立物品等级抽普通／银星／金星。拾取、转手和自动化不重抽；铁砧修理沿用主物品品质。
- 银星售价×2、装备适用属性与耐久×1.2；金星售价×6、适用属性与耐久×2，并额外有10%永久无限耐久。职业经验用大整数保存，100级后继续增长；职业等级超过物品等级10级时经验减半，超过30级时每件1点。
- 岛屿等级使用当前方块存量，升级需求依次为100、300、600、1000等，无100级上限。出售按物品ID共享日累计：1～128件10%、129～320件5%、321～640件1%、其后0.5%；行情、品质、合法附魔、耐久与阶梯使用有理数计算，整单最终取整一次。
- 主世界时钟每跨过04:00统一换日、重抽行情与每日供货、清库存及出售计数，并广播刷新提示。岛内玩家第N次死亡扣N点队伍余额，可扣成负数；购买仍须余额足额。重开清死亡计数，所有世界复活后饥饿值设6。
- 控制面板显示YUMIS及岛屿本级进度，移除卖出手持入口；任务不再使用介绍字段，物品及生物名在客户端从语言包读取；所有自有确认浮层共用组件，Enter与确认按钮走同一路径。购买、死亡、正负金额和个人职业经验使用左下角／钱包旁浮动提示。
- `economy.toml` 的 `genshinMode` 默认开启，本次仅将货币称呼切换为“摩拉”；关闭后显示“金币”。21份TOML默认配置与开发实例同步。70件职业装备默认设为仅收购，基础估值由26.2有效配方中最低材料成本生成，缺失材料估值会在加载时报错。

## 实测

- `./local-tests/run.ps1 -Task Unit -Offline`：50项JUnit，0失败。覆盖品质概率边界、100级曲线拐点与高等级、10／30级经验衰减、128／129及320／321及640／641件报价、负钱包与购买拒绝、持久化、星级装备属性及最低配方价值。
- `./tools/dev.ps1 -Task GameTest -Offline` 定向三组隔离客户端场景：原版制作、Shift批量制作、切石、熔炼领取、钓获、成熟作物破坏、本人／投射物击杀、任务及重开；另验证04:00自然经过、跳时、同日防重、金星实际掉落、死亡两次扣1再扣2、负余额购买拒绝、中文购买提示和统一确认框Enter防重。第三组使用普通世界真实死亡与复活，验证空岛服务不启动且饥饿值为6。
- `./tools/dev.ps1 -Task Check -Offline` 与 `./tools/dev.ps1 -Task Export -Offline` 通过。导出脚本逐份比对JAR内21份默认TOML与当前配置源哈希，并检查测试内容未打入JAR。开发实例的21份TOML与配置源逐份哈希一致。

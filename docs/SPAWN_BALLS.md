# 刷怪球与矿工宝石奖励

2026-10-20确认。刷怪球是永久区块消耗品，不是刷怪蛋或刷怪笼；以下商品价格、库存和等级均可由既有物品管理编辑。

## 使用与清除

正式队员手持刷怪球右键，在本队三种空岛维度中，把本人所在16×16区块全高度的自然敌对刷怪改为该种生物。每次成功消耗1颗；相同种类重复使用不消耗，换种消耗新球且不返旧球。等级只限制商店购买，已购球可正常转交和使用，掉级不会停止效果。普通生存世界、访客及外队领地不能使用。

`/is spawnball info` 查看所在区块记录；`/is spawnball clear` 免费恢复原版自然刷怪，不返球。全局关闭时仍可查看或清除记录。

陆地怪需要可站立地面，守护者、溺尸需要至少容纳身体的水体（脚部及上方水格）。保留空间、所在维度普通敌对光照、原版玩家距离、难度及数量上限；取消目标原版群系、结构、维度、史莱姆区块及高度门槛。环境本身的原版行为保留，例如在下界放水仍受原版机制约束。

球只改变今后自然生成的目标，不转换已有实体，也不干预刷怪笼、袭击、召唤等生成途径。AI、装备、掉落和消失沿原版；猎人／战斗经验、击杀任务及玩家击杀要求沿既有规则。主世界血月仍使用现有亮度、尝试次数、容量、强化和饰品掉落，不额外叠加刷怪球倍率。

## 保存、配置与性能边界

队伍 `spawnOverrides` 按“维度|打包区块坐标”保存种类，扣球与记录通过背包恢复事务同笔落盘。索引仅在启动和持久化成功后建立／更新；失败不发布新效果。重启保留；换队资产留原队；重开删除主世界球记录，下界与末地随既有建筑保留，重开期间暂停操作。

`gameplay/spawn_balls.toml` 的 `enabled` 默认true，关闭时禁止使用并暂停效果，保留实物与记录；恢复开启并重启后继续生效。商品供货独立沿商品交易开关控制。该文件中文注释、手改重启，不在实时编辑白名单内。

`SpawnBallService` 管理记录与按维度／区块直接查询的索引；`SpawnBallSpawnerMixin` 只拦截26.2 `NaturalSpawner` 自然刷怪调用链，在创建实体前按每个实际位置确定种类。不同种类之间清空生成组上下文；越出效果区恢复当地自然候选。保留原版容量谓词和成功回调，史莱姆／岩浆怪最终随机体型在加入世界前再检查碰撞，失败不进入容量计数。

没有额外tick任务、怪物遍历、实体删除替换、区块票据或离线追赶。每次自然刷怪只增加常数时间策略查询及必要场地检查，索引变更不属于刷怪热路径。实际产量仍受原版尝试、容量、玩家位置和玩家建造条件影响。

## 矿工宝石奖励

持锤敲圆石时，矿工75～99级钻石概率由1%降至0.1%，新增绿宝石0.2%；100级起钻石由3%降至0.3%，新增绿宝石0.6%。等级档互斥，每块各条目独立判定、各1件，可同出；连锁逐块判定。75级前不新增宝石奖励。

规则仍集中在 `HammerRules`，JEI共用同一份概率数据。保持普通无品质产物和实际掉落任务统计，不改变天然矿石掉落、时运、其他奖励或职业经验；没有新增概率TOML、网络协议或旧档迁移。
